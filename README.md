# Трекер привычек

Минималистичный трекер привычек: без аккаунтов, без интернета, данные — только на устройстве.

## Быстрый старт на ПК

Откройте `index.html` двойным кликом — работает в Chrome, Edge, Firefox, Safari.

> Данные браузер хранит отдельно для каждого адреса. Если открываете файл локально — не переименовывайте и не перемещайте папку, иначе браузер «потеряет» историю. Для надёжности делайте экспорт (Настройки → Экспорт JSON).

## Открыть на телефоне по Wi-Fi (без интернета и регистраций)

1. Убедитесь, что телефон и компьютер в одной сети Wi-Fi.
2. Дважды кликните `открыть-на-телефоне.bat` — откроется чёрное окно с адресом.
3. Введите этот адрес в браузере телефона, например: `http://192.168.1.103:8765/`
4. Чтобы остановить — закройте окно на компьютере.

Что важно знать:
- Пока окно открыто и компьютер включён — приложение доступно телефону.
- Данные, введённые на телефоне, хранятся **на телефоне** (у каждого устройства своя история). Перенос — через экспорт/импорт JSON в настройках.
- Установка на главный экран и уведомления в этом режиме недоступны: браузер разрешает их только для `https://`.
- Если страница на телефоне не открывается: запустите `разрешить-доступ-с-телефона.bat` (попросит права администратора), затем повторите. Также проверьте, что в роутере не включена «изоляция клиентов AP».

Для постоянного использования (иконка на телефоне, работа без компьютера) — установка через Netlify ниже.

## Установка на Android

Приложение — это PWA: его можно поставить на главный экран и пользоваться как обычным приложением, офлайн.

Для установки нужен адрес `https://` (или `localhost`). Самый простой бесплатный способ:

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop) на компьютере.
2. Перетащите папку `habit-tracker` целиком в окно браузера.
3. Получите ссылку вида `https://random-name.netlify.app`.
4. Откройте её в Chrome на телефоне.
5. Меню Chrome (⋮) → **«Установить приложение»** (или «Добавить на главный экран»).
6. Иконка появится на рабочем столе, приложение откроется без адресной строки и будет работать офлайн.

Альтернативы: GitHub Pages, Vercel, Cloudflare Pages — подойдёт любой статический хостинг, сборка не нужна.

> Пока приложение не установлено и открыто по `file://`, системные уведомления и офлайн-кэш браузер не разрешает — это ограничение браузеров, а не приложения.

## Что внутри

**Неделя** — сетка привычек по дням, серии, рубежи, челлендж недели, итоги прошлой недели.

**Сегодня** — только актуальные привычки крупными кнопками.

**Месяц** — календарь с интенсивностью выполнения.

**Аналитика** — уровень и опыт, достижения, динамика за 12 недель, пропуски по дням недели, карта года.

**Отметки**
- Клик по клетке — выполнено / снять.
- Правый клик или долгое нажатие — минимум, заморозка (2 в месяц), заметка.
- Числовые привычки: клик открывает ввод значения (цель, шаг, единица).

**Данные** — экспорт JSON/CSV, импорт, ежедневные резервные копии (7 дней), архив привычек.

**Горячие клавиши** — `1`…`9` отметить привычку, `N` новая, `←` `→` недели, `Ctrl+Z` отмена.

## Файлы

```
index.html            разметка и диалоги
css/app.css           стили
js/util.js            утилиты и даты
js/store.js           хранение, миграция, бэкапы, экспорт
js/logic.js           серии, статистика, достижения
js/ui.js              экраны и компоненты
js/app.js             события и запуск
sw.js                 офлайн-кэш
manifest.json         описание PWA
_headers              заголовки для статического хостинга
icons/                иконки
legacy/index-v1.html  первая версия (только для истории)
```

Данные из первой версии переносятся автоматически при первом запуске.
